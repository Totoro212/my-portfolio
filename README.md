# Портфолио: Разработка веб-приложений под бизнес-задачи (Fullstack)

Минималистичное веб-портфолио в **светлых тонах**, созданное исключительно на **чистом HTML5 и CSS3** без сторонних фреймворков и скриптов.

Портфолио позиционирует вас как **инженера, решающего бизнес-задачи и создающего веб-приложения**, а Laravel и PostgreSQL представлены как надёжные инструменты под капотом.

---

## 🎯 Бизнес-архитектура портфолио

### 1. Продуктизация услуг (Пакеты вместо почасовки)
Вместо размытых оценок портфолио разделяет услуги на 3 понятных этапа с фиксированным результатом:
* **Часть 1: Технический аудит & Roadmap (Входной билет)** — Профилирование медленных запросов в PostgreSQL (EXPLAIN ANALYZE), аудит безопасности по OWASP Top 10, выявление узких мест с дорожной картой исправлений (срок 2–4 дня).
* **Часть 2: Разработка под ключ / MVP (Основной проект)** — Создание веб-сервиса, личного кабинета или API на Laravel 11 с базой PostgreSQL и чистым интерфейсом. Фиксированные сроки, поэтапная оплата (50/50).
* **Часть 3: Поддержка & Безопасность (Подписка / SLA)** — Резервное копирование БД, обновления безопасности, мониторинг доступности и включённый пакет часов на доработки по фиксированному SLA.

### 2. Кейсы с измеримыми результатами для бизнеса
Каждый проект в секции `#projects` построен по формуле:
`Проблема клиента` &rarr; `Инженерное решение` &rarr; `Измеримый финансовый / технический результат`:
* *Кейс 1 (CRM & PostgreSQL)*: «Ускорение отчётов в 8.5 раз &bull; −45% CPU &bull; 0 потерь данных».
* *Кейс 2 (REST API & Автоматизация)*: «10,000+ заявок/день &bull; обработка за 3 сек &bull; 0 потерянных лидов».
* *Кейс 3 (E-Commerce Каталог)*: «Загрузка < 0.9 сек &bull; 100/100 Lighthouse &bull; +28% к конверсии».

## 💻 Стек и технологии

* **Бэкенд**: PHP 8.x, Laravel 11 (MVC, Service Layer, Eloquent ORM, REST API, Queues & Jobs, Sanctum).
* **База данных**: PostgreSQL (проектирование реляционных схем, ACID-транзакции, индексы B-Tree/GIN, оптимизация EXPLAIN, JSONB).
* **Фронтенд**: Чистый семантический HTML5, адаптивный современный CSS3 (Grid & Flexbox, кастомные свойства, `clamp()`), Blade-компоненты.
* **Безопасность**: Защита от SQL-инъекций (параметризованные запросы/Eloquent), CSRF, XSS, хеширование паролей, строгая Content-Security-Policy.

---

## 🛡️ Безопасность и стандарты (Best Practices)

1. **Строгая Content-Security-Policy (CSP)**:
   ```html
   <meta http-equiv="Content-Security-Policy" content="default-src 'self'; style-src 'self'; img-src 'self' data:; font-src 'self'; base-uri 'self'; form-action 'self' mailto:;">
   ```
2. **Защита от Reverse Tabnabbing**: Все внешние ссылки содержат `target="_blank" rel="noopener noreferrer"`.
3. **Семантика HTML5 и A11y (WCAG 2.1 AA+)**:
   - Специальная ссылка для перехода к содержимому (`.skip-link`).
   - Контрастный фокус `:focus-visible`.
   - Режим пониженного движения (`prefers-reduced-motion`).
4. **Прямые каналы связи**: Минималистичная карточка прямых контактов (Telegram, Email, GitHub) без архаичных неработающих форм.

## 🛠️ Как кастомизировать под свои задачи

В файле [index.html](file:///c:/Users/Sen/Desktop/my/index.html):
1. **Своё имя и заголовки**: обновите поле `$name = "Ваше Имя"` в блоке `.code-card` и мета-теги `<title>`.
2. **Пакеты услуг (`#services`)**: скорректируйте состав услуг, сроки и цены под ваши реальные предложения.
3. **Кейсы (`#projects`)**: вставьте ваши реальные цифры и результаты (на сколько % ускорили, сколько $ сэкономили клиенту).
4. **Контакты (`#contact`)**: укажите ваши реальные Telegram-логин и Email.
